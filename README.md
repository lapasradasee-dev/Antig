## 🚀 การเปิดใช้งาน (Getting Started)

1. เปิด Terminal ในโฟลเดอร์นี้
2. รันคำสั่งเซิร์ฟเวอร์:
   ```bash
   node server.js
   ```
3. เปิดเว็บเบราว์เซอร์แล้วไปที่:
   ```
   http://127.0.0.1:3000/
   ```
*(สามารถเปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ได้โดยตรงเช่นกัน)*
